    Glossary

    How every return on this page is measured

    TWR · time-weightedChains sub-period returns so deposits and withdrawals do not matter. Answers: how good was the strategy? Used for Epoch return.
    MWR · money-weightedAnnualised internal rate of return on the actual cash flows. Answers: what did the dollars earn? Moves with the timing of deposits.
    RONC · return on net capitalGain ÷ (capital in − withdrawn). Ignores timing, so late money lowers it. A diagnostic, not a performance figure.
    Epoch returnCumulative TWR over one account × strategy window (earlier labelled “Accepted return”). Not annualised.
    Annualised · window-equivalentAn annualised figure is only shown as a result for windows of 365 days or more. Below that it is labelled “annualised from N days” and the window-equivalent, (1 + rate)days/365 − 1, is shown beside it so it can be compared with the cumulative TWR.
    Observed return, HWM, drawdownDiagnostics over the linked NAV intervals; not accepted TWR or MWR.

      Interpretation boundary

      Beta (also called a loading or fitted exposure) is return sensitivity, not a holding. Net alpha is reported only on the observed return basis. Gross alpha stays unavailable until cost coverage is complete. Raw proxies are not assumed orthogonal. Eligible OLS models report descriptive HAC standard errors and residual diagnostics, never post-selection p-values or confidence intervals. Factor, alpha, fitted return, and residual reconcile within the accepted analytics tolerance.

        Operator glossaryControl, return, evidence, and methodology termsOpen glossary
        HWM
        High-water-mark risk control over the governed systematic perimeter. It remains unavailable when required daily NAV evidence is stale, missing, or outside the accepted boundary.
        TWR / MWR
        Time-weighted return removes external-flow timing; money-weighted return reflects the investor experience and requires complete external-flow evidence.
        Evidence state
        Whether an accepted source observation exists for the declared account, strategy, fact, and date boundary.
        Model state
        Whether an estimator was computed, validated, diagnostic-only, rejected, or unavailable. It never upgrades source evidence.
        Gate state
        A fail-closed readiness control. Missing evidence stays unavailable and cannot become a silent zero or inferred pass.
        MPI-informed, non-equivalent
        A clean-room implementation of openly described dynamic style-analysis concepts. It does not claim proprietary MPI code, defaults, or production equivalence.
